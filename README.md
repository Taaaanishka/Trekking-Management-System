# Trekking-Management-System
A web-based Trekking Management System developed using Flask, SQLite, HTML, CSS, and Bootstrap. The application provides separate interfaces for administrators, trek staff, and trekkers to manage trekking activities, users, bookings, and trek assignments.

Features
👤 User registration and login
🥾 Browse available treks
📅 Trek booking management
👨‍💼 Admin dashboard
👷 Trek staff management
🗺️ Assign staff to treks
📋 Manage users and bookings
🔍 Search functionality
🚫 User/staff approval and blacklisting
📊 Trek and booking management
